## Database `CARS_DEMO`

CARS_DEMO demo database. RelationalAI fleet-recall-propagation demo. Source-of-truth tables under schema FLEET; agent under schema RAI_AGENT once Phase 7 is complete. Generated by data/build_cars_demo_data.py.

## Schema `CARS_DEMO.FLEET`

Vehicle fleet operational data: vehicles, owners, service events, recall campaigns, suppliers, parts, bill-of-materials, service-centre capacity and parts-stock. Used by the cars PyRel model.

## Tables

### `CARS_DEMO.FLEET.dim_supplier`

Tier-1 suppliers (Continental, Bosch, ZF, Samsung SDI, ...). Anchored by supplier_id. Source of Act 2 cascade traversal.

Tags: `DATA_DOMAIN=SOURCING`, `TABLE_ROLE=DIMENSION`, `GRAIN=STATIC`, `DEMO_AREA=RECALL`

| Column | Description |
|---|---|
| `supplier_id` | Short stable identifier (SUP-CONT, SUP-BOSCH, ...). Primary key. |
| `name` | Legal supplier name (e.g. Continental AG). |
| `tier` | Position in the supply chain. 1 = direct supplier to the OEM. |
| `country` | ISO-3166 country code of the supplier HQ. |
| `specialty` | Free-text capability summary used in the talk track. |
| `warranty_share_pct` | Percentage of warranty cost the supplier is contractually reimbursed for under PPAP. |

### `CARS_DEMO.FLEET.dim_region`

Geographic regions used for Act 2 rollups (EU / NA / LATAM).

Tags: `DATA_DOMAIN=LOCATION`, `TABLE_ROLE=REFERENCE`, `GRAIN=STATIC`, `DEMO_AREA=GEO`

| Column | Description |
|---|---|
| `region_code` | Region key (EU-DE, EU-WE, US-WEST, MX, ...). Primary key. |

### `CARS_DEMO.FLEET.dim_plant`

BMW production plants matched to the seed CSV's FACTORY_PRODUCTION_LOCATION values. Each plant has a single-letter code that matches BMW's VIN-position-11 convention.

Tags: `DATA_DOMAIN=PRODUCT`, `TABLE_ROLE=DIMENSION`, `GRAIN=STATIC`, `DEMO_AREA=PRODUCTION`

| Column | Description |
|---|---|
| `plant_code` | Single-letter VIN-position-11 plant code. Primary key. D=Dingolfing, M=Munich, R=Regensburg, K=Spartanburg, B=Leipzig, T=San Luis Potosi. |
| `name` | Plant name as it appears in vehicle.factory. |
| `country` | ISO country (DE, US-SC, MX). |
| `region_code` | Plant region for rollup. |
| `weekly_output` | Approximate weekly vehicle output. Reference only. |

### `CARS_DEMO.FLEET.dim_part`

Parts catalogue with supplier and category. Anchor for Act 2 cascade and Act 4 parts-stock constraint.

| Column | Description |
|---|---|

### `CARS_DEMO.FLEET.dim_bom_node`

Bill-of-materials nodes. Each node ties a part to a model-fragment + plant + production-date-window cohort. Used by bom_membership to materialise the supplier-to-VIN cascade.

Tags: `DATA_DOMAIN=PRODUCT`, `TABLE_ROLE=NETWORK_GRAPH`, `GRAIN=STATIC`, `DEMO_AREA=RECALL`

| Column | Description |
|---|---|
| `bom_id` | BOM node id (BOM-IBS-MUN-01, ...). Primary key. |
| `part_id` | FK to dim_part. |
| `description` | Free-text description used in the cascade visualisation. |
| `applies_to_model_codes` | Pipe-separated model-name fragments. A vehicle is a member if its MODEL contains any of these substrings. |
| `applies_to_plants` | Comma-separated plant_codes the cohort applies to. |
| `applies_from` | Start of the production-date window (inclusive). |
| `applies_to` | End of the production-date window (inclusive). |

### `CARS_DEMO.FLEET.dim_service_centre`

Service centres in the network with tooling certifications. Capacity per week lives in centre_capacity (separate table because it's time-varying).

Tags: `DATA_DOMAIN=LOCATION`, `TABLE_ROLE=DIMENSION`, `GRAIN=STATIC`, `DEMO_AREA=SERVICE`

| Column | Description |
|---|---|
| `centre_id` | Centre id (SC-MUN, SC-COL, ...). Primary key. |
| `name` | Centre name as in service_event.service_centre. |
| `country` | ISO country. |
| `region_code` | FK to dim_region. |
| `hv_certified` | True iff the centre is high-voltage certified for HV battery work. |
| `ibs_certified` | True iff IBS-trained for brake-booster firmware campaigns. |
| `body_shop` | True iff the centre has body-shop capability for restraint-system work. |
| `weekly_tech_hours` | Default weekly technician-hour budget (overridden per week in centre_capacity). |
| `has_egr_tooling` | True iff equipped for EGR cooler replacement. |

### `CARS_DEMO.FLEET.dim_recall_campaign`

Active and historical recall campaigns. Severity codes follow KBA/NHTSA conventions: 1 = stop driving, 2 = repair urgently, 3 = scheduled.

Tags: `DATA_DOMAIN=RISK`, `TABLE_ROLE=REFERENCE`, `GRAIN=STATIC`, `DEMO_AREA=RECALL`

| Column | Description |
|---|---|
| `campaign_id` | Campaign id (IBS-2024-A, HVB-2024-A, ...). Primary key. |
| `name` | Campaign name as used in the talk track. |
| `supplier_id` | FK to dim_supplier (defect originator). |
| `primary_part_id` | FK to dim_part (the defective part). |
| `severity_code` | 1 = Code 1 stop driving, 2 = Code 2 repair urgently, 3 = scheduled. Source of Act 1 SLA gate. |
| `completion_days` | SLA window measured from per-VIN notified_on. Source of Act 1 breach computation. |
| `announced_on` | Date OEM publicly announced the campaign. |
| `requires_hv_cert` | Eligibility constraint for Act 4: a centre needs HV cert to take this campaign's jobs. |
| `requires_ibs_cert` | IBS trained. |
| `requires_body_shop` | Body shop for restraint-system work. |
| `typical_labour_hours` | Average flat-rate hours per job. Used in Act 4 capacity sizing. |
| `description` | Free-text defect summary used in the talk track and Cortex agent answers. |

| `serial_number` | Internal BMW serial. |
| `model` | Model designator including code (e.g. '3 Series 330i (G21 LCI)'). |
| `factory` | Plant name. FK to dim_plant.name. |
| `engine_type` | Engine family code. |
| `fuel_type` | Petrol / Diesel / Electric / Hybrid. |
| `transmission` | Manual / Automatic. |
| `chassis_number` | Internal chassis number. |
| `emission_standard` | EURO 6e-bis / Zero Emission. |
| `production_date` | Off the line at plant. |
| `delivery_date` | First delivery to dealer. |
| `first_registration_date` | First owner registration (start of age-in-service clock). |
| `mileage` | Current odometer (km). |
| `fuel_consumption` | Quoted figure. |
| `accident_date` | Most recent accident on file (nullable). |
| `accident_type` | Minor / Vandalism / Rear-end / Collision (nullable). |
| `repair_cost` | Most recent repair cost. |
| `service_records` | Up to date / Partial (free text). |

| `power_output_kw` | Motor power (kW). |

### `CARS_DEMO.FLEET.recall_assignment`

(VIN, campaign) row representing the OEM's open work item per vehicle per campaign. Generated by data/build_cars_demo_data.py from BOM membership + per-campaign Open/Closed/In Progress distribution.

Tags: `DATA_DOMAIN=RISK`, `TABLE_ROLE=FACT`, `GRAIN=EVENT`, `DEMO_AREA=RECALL`

| Column | Description |
|---|---|
| `recall_id` | Primary key. |
| `vin` | FK to vehicle. |
| `campaign_id` | FK to dim_recall_campaign. |
| `status` | Open / In Progress / Closed. |
| `announced_on` | Campaign announcement date (constant per campaign). |
| `notified_on` | Per-VIN owner-notification date. Drawn from a notification-lag distribution; some VINs are notified months after the campaign announcement (expanded scope). |
| `closed_on` | Set when status='Closed'. |
| `age_days_at_demo` | DEMO_DATE - notified_on, in days. |
| `mileage_at_assign` | Vehicle mileage at the time the recall_assignment was created. |
| `sla_breached` | Pre-computed in the data layer for SQL audits. The PyRel ontology recomputes the same predicate as a derived property over the model. TRUE iff status='Open' AND age_days_at_demo > campaign.completion_days AND severity_code <= 2. |

### `CARS_DEMO.FLEET.centre_capacity`

Per-centre per-week technician-hour budget over the 4-week Act 4 planning horizon. Capacity varies slightly per week (e.g. holiday cover dips at Munich + Cologne in week 2).

Tags: `DATA_DOMAIN=SERVICE`, `TABLE_ROLE=FACT`, `GRAIN=WEEKLY`, `DEMO_AREA=SERVICE`

| Column | Description |
|---|---|
| `centre_id` | FK to dim_service_centre. |
| `week_index` | 1..4 within the planning horizon. |
| `tech_hours_available` | Tech-hours capacity available in that centre that week. |

### `CARS_DEMO.FLEET.parts_stock`

Per-centre per-campaign per-week on-hand stock. The binding constraint of Act 4: Continental cannot ship enough booster ECUs in the planning horizon to cover all open IBS-2024-A jobs.

Tags: `DATA_DOMAIN=SOURCING`, `TABLE_ROLE=FACT`, `GRAIN=WEEKLY`, `DEMO_AREA=RECALL`

| Column | Description |
|---|---|
| `centre_id` | FK to dim_service_centre. |
| `campaign_id` | FK to dim_recall_campaign. |
| `week_index` | 1..4 within the planning horizon. |
| `on_hand_units` | Units on hand at the start of that week. Decrements implicitly when jobs are assigned (the LP enforces sum(assign[c,w,*]) <= on_hand[c,w]). |
